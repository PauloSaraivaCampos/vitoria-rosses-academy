# Vitória Rosses Academy — demonstração

Protótipo estático para testes de navegação, cursos e permissões.

## Publicação no GitHub Pages
1. Crie um repositório público `vitoria-rosses-academy`.
2. Envie todos os arquivos deste ZIP para a RAIZ do repositório (index.html e imagens).
3. Em Settings > Pages > Build and deployment, selecione Deploy from a branch, `main`, `/(root)` e Save.
4. Aguarde a publicação e acesse `https://SEU-USUARIO.github.io/vitoria-rosses-academy/`.

## Atenção
Este é um DEMO. O login, os pagamentos e as permissões não são seguros para produção: os dados ficam no navegador. Não use com alunos reais ou cobranças. Para a versão comercial, será necessário backend com autenticação e permissões no servidor, banco de dados e gateway de pagamento.
